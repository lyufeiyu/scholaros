# 本地 IEEEtran 模板

本目录保存 ScholarOS 使用的 IEEE 期刊 LaTeX 模板源文件，生成稿件时读取其中的 `IEEEtran` 期刊骨架。

- 来源：CTAN `macros/latex/contrib/IEEEtran.zip`
- 下载日期：2026-09-22
- 关键文件：`IEEEtran/IEEEtran.cls`、`IEEEtran/bare_jrnl.tex`、`IEEEtran/bibtex/IEEEtran.bst`
- 模板许可证与使用边界以归档内的 `README`、`changelog.txt` 和上游许可说明为准。

该模板只负责排版骨架，不代表稿件已经符合某个具体 IEEE 期刊的投稿要求；投稿前仍需按目标期刊最新 Author Center 指南核对文档类选项、匿名要求、参考文献和图表规范。
