ScholarOS 的公开文档只描述稳定接口、使用边界和公开产品定位；内部实现历史、内部项目代号、调试记录、用户数据和密钥都不应提交到仓库。提交前请确认 `.env` 已被 `.gitignore` 忽略，且文档中不出现真实密钥。

外部服务条款、模型名称、API 限额和开放获取政策可能变化；涉及权限的决定应以对应服务的当前官方条款和论文许可证为准。

所有生成内容均是供研究者核验和修改的工作材料。公开介绍不得把 ScholarOS 描述为自动作者、论文代写工具或研究质量保证系统。
