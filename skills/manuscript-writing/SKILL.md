# 论文起草与修订

若显式选择 IEEE 期刊，先将整篇稿件写成英文，使用与 IEEEtran 期刊结构相符的英文标题、Abstract、Keywords、Introduction、Methods、Results/Results Reporting Protocol、Discussion、Conclusion、References 等分段；中文源材料应由模型忠实改写并保留证据边界，不能把中文稿悄悄退回通用 LaTeX 模板。无法可靠改写时明确阻塞，不伪造译文或成果。维持题目、摘要、方法、图表、结果与参考文献之间的语义一致。保留合法 `[@cite_key]`，未验证的信息明确留待核实；没有结果资料时写研究方案，不制造结果。署名、披露和最终投稿决定属于研究者。
